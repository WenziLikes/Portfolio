# Security Policy

[Documentation hub](./docs/README.md)

## Supported Version

Security fixes apply to the current version on `main` and the production deployment at [viacheslavmurakhin.com](https://viacheslavmurakhin.com/). Older commits and preview deployments are not maintained as separate supported versions.

## Report a Vulnerability Privately

Use GitHub's private vulnerability reporting flow:

1. Open the repository's [Security tab](https://github.com/WenziLikes/Portfolio/security).
2. Select **Report a vulnerability**.
3. Describe the affected route or component, impact, reproduction steps, and any suggested mitigation.

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or social post. The private advisory is the place to coordinate validation and disclosure with the maintainer.

Reports about third-party services should identify the service and explain how the portfolio integration is affected. This repository cannot remediate vulnerabilities that exist only in an external provider, but integration-level risks are still relevant.
